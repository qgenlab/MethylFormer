## Validation of DMR Detection Using Promoter Activity States
### 1. Benchmark Generation
Before validating, you need to generate the reference database. Navigate to the ActivitySearch directory and run the setup scripts:

```
cd DiffMethylTools2/Reproducibility/test_results2/ActivitySearch/
./get_gff_file.sh
python ./generateDB.py
```

get_gff_file.sh: Downloads the necessary .gff annotation files.

generateDB.py: Normalizes the downloaded files and structures them into a database for fast, easy access during validation.

### 2. Results Generation
Return to your main output directory to run the final testing script. You will need to provide the paths to the three output folders previously generated by run_sota.sh.

```
./test_results2.sh <path_to_B_NK> <path_to_NK_Monocytes> <path_to_B_Monocytes>
```

Parameters:

<path_to_B_NK> : Path to the B_NK/ results folder.

<path_to_NK_Monocytes> : Path to the NK_Monocytes_res/ results folder.

<path_to_B_Monocytes> : Path to the B_Monocytes_res/ results folder.

#### Output Files
The script will analyze the data and generate a results/ subdirectory inside each of the three folders you provided. Inside, you will find the following metric files:

dmr_all.csv : Absolute count of DMR (Differentially Methylated Region) overlap between tools.

dmr_all_perc.csv : Percentage of DMR overlap between tools.

dml_all.csv : Absolute count of DML (Differentially Methylated Loci) overlap.

dml_all_perc.csv : Percentage of DML overlap.

dml_non_isolated.csv : Count of non-isolated DML overlap.

dml_non_isolated_perc.csv : Percentage of non-isolated DML overlap.

dml_clustered.csv : Count of clustered DML overlap.

dml_clustered_perc.csv : Percentage of clustered DML overlap.
