To download simulation data, run 
```
bash run.prepare_benchmark.sh
```
To preprocess simulation data, run
```
bash simulationdata/get_data.sh
```

To test the results, run
```
bash test_simulation.sh "PATH_TO_SIMULATION_RESULTS_FOLDER" "PATH_TO_BENCHMARK"
```

For "PATH_TO_BENCHMARK" choose one of: 
simulationdata/DMRs/DMR.artif.chr10.WGBS_background.1_DMR.class.1.bed
simulationdata/DMRs/DMR.artif.chr10.WGBS_background.1_DMR.class.2.bed
simulationdata/DMRs/DMR.artif.chr10.WGBS_background.1_DMR.class.3.bed
simulationdata/DMRs/DMR.artif.chr10.WGBS_background.1_DMR.class.4.bed
